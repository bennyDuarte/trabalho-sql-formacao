# Trabalho de SQL - Formacao Tecnico de Desenvolvimento de Software

Trabalho final da UC 02830, desenvolvido nas aulas e em reuniões de grupo externas.
O tema escolhido foi uma loja de componentes, baseada no site da empresa Mauser.
___
O código foi desenvolvido maioritariamente de forma manual, mas houve recurso a IA para apoiar a construção do sistema de faturação (nomeadamente a query) e para a verificação de gralhas e erros de código.
